# 文风规范

## 默认参数

| 项 | 默认 | 说明 |
|---|---|---|
| 视角 | 第三人称限知 | 随场景切换，不在一段内跳视角 |
| 时态 | 过去时 | 不用"他正在…"的进行时堆叠 |
| 每页字数 | 120–180 | 一话 = 页数 × 区间 |
| 台词 | 逐字 + 方言保留 | 只加"他说"类标签 |
| 分段 | 场景切换用 `◇` | 一话 2–6 段 |
| 比喻 | 每 800 字 ≤ 1 个 | 宁缺勿滥 |

## 场景写法

开头一句给三样东西：**地点、时间、一个感官细节**。

> 正殿的香烧到一半，灰落在青砖上，没人去扫。

不写：

> 画面中是一座正殿，时间似乎是白天。

## 动作写法

拆到身体、光影、声音。

| 不要 | 改成 |
|---|---|
| 他非常生气 | 他指节压在桌沿，木头发出一声轻响 |
| 气氛很紧张 | 没人接话，茶盏里的水面晃了一下 |
| 她飞快地出手 | 她手腕一翻，袖口带起一阵风 |
| 两人对视良久 | 他抬眼看过去，对方没有避开 |

## 台词

- 逐字保留 `outline.quotes`，方言原样：`噻` `嘞` `啥子` `咋个` `恁个`。
- 只加必要的标签：`他说`、`她把声音压下去`、`他头也不抬`。
- 台词前后**不要重复解释台词的意思**（"他的意思是……"）。
- 连续对话超过 4 轮，插一个动作或环境，别写成剧本。

```
"只有咱们这一门噻！"他把令牌举高，指腹在缺角上蹭了一下。
```

## 禁止

**分镜词汇**（正文中零容忍）：画面、镜头、分镜、这一格、格子、读者、漫画、对话框、旁白框、画外音。

**偷懒句式**：仿佛在说、似乎在诉说着、不禁、不由得、心中一凛、空气仿佛凝固——一段最多出现一个同类。

**编造**：原图没有的人物、能力、门派、前情。需要衔接时只用 `outline.continuity` 里写明的信息。

**整段复述台词**："他说……他又说……"——台词之间必须有动作或环境。

**连续三段以"他"开头**。

## 战斗段落

- 一句一个动作，句子短。
- 拟声词单独成句或作短句成分：`铛。` `骨节错了位。`
- 不用长定语修饰招式：写"他从下往上撩了一刀"，不写"一记蕴含毁天灭地之力的自下而上的刀"。
- 打完给一个静止镜头式的短句收束（但不要写"镜头"两个字）：`风停了。`

## 文戏段落

- 靠对话和停顿推进，少堆形容词。
- 心理只写 pov 人物，且必须是画面能支撑的情绪，不虚构回忆。
- 沉默要写出来：`他没接话。`

## 视角切换

- 只在 `◇` 处切换。
- 切进新视角的第一段，先给这个人**看到/听到**的东西，再给判断。
- 一话内主视角不超过 3 个。

## 标题与元数据

```markdown
---
话: 143
标题: 日月炼果
页数: 57
场景: [正殿, 后山, 夜雨长街]
人物: [陈松, 皓光, 明子]
字数: 4820
---

# 第一百四十三回 日月炼果
```

番外：`# 番外 咳咳之道`，`话: 72.5`。

## 自检行

正文末尾留一行 HTML 注释，方便脚本核对：

```html
<!-- selfcheck: 字数=4820 台词=18/18 禁词=0 场景=4 -->
```

## 不同文风的旋钮

| 想要 | 调什么 |
|---|---|
| 更"金庸" | 句子加长、多用四字结构、动作干净、少心理 |
| 更"网文" | 句子变短、多分段、心理独白增多、每段留钩子 |
| 更"文学" | 感官细节加密、允许留白、对话减少、比喻克制但精确 |
| 更适合朗读 | 句子短、少生僻字、少括号、拟声词口语化 |

调完写进 `config.json`，全项目统一。
