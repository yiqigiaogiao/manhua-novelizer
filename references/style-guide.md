# 写作参数（v0.3）

> 本文件只保留**技术参数**。文风判断一律看 `references/principles.md` 与 `work/style.md`。
> v0.3 起**取消字数上下限**、**取消禁用词表**。

## 技术参数

| 项 | 默认 | 说明 |
|---|---|---|
| 视角 | 第三人称限知 | 按 `config.adaptation.pov`；一段之内不跳视角 |
| 时态 | 过去时 | 按 `config.adaptation.tense` |
| 台词 | 逐字 + 方言保留 | 按 `config.adaptation.dialect` |
| 分段 | 场景切换用 `◇` | 单独一行 |
| 篇幅 | 不设限 | 由事件密度与节奏决定 |

## 不做什么

- 不写"画面中／镜头／这一格／读者"这类说明语言（`forbid_meta_language`）。
- 不为了凑长度补环境、补心理、补回忆。
- 不给每章结尾加悬念句。

## 为什么取消字数与禁词

- **字数**：不同话的信息密度差好几倍，用页数推字数会把"留白多的文戏"灌水、把"信息密集的打斗"压扁。
- **禁词**：一张词表既拦不住 AI 腔，又会误伤正常表达（"画面"在人物对话里可能是合法用词）。
  真正的约束是 `references/principles.md` 里的十二条与 A/B/C 补写分级。

## 质量看什么

1. 台词覆盖 ≥ 95%（机器）
2. 事件完整性（agent）
3. 忠实度：无编造、无张冠李戴（agent 抽页）
4. 声音一致性（agent）
5. 风格执行：逐场判断，不机械套用（agent）
