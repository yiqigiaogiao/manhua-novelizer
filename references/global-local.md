# 全局层与局部层：为什么不能互相替代

## 两层的分工

```
┌─ 全局层 ─────────────────────────────┐
│ spine.md      全书主线、人物弧、伏笔   │  便宜：低清取样通读
│ bible.md      设定、称谓、术语         │  只在写作前建一次
│ 节奏表        各话强度曲线             │
└──────────────────────────────────────┘
                 │ 只用于查一致性
                 ▼
┌─ 局部层 ─────────────────────────────┐
│ page_script.json  逐页逐格，一格不漏   │  贵：高清逐页精读
│ outline.json      索引：这场用哪几页   │  每话都要做
│ draft.md          正文                │  写到哪场翻哪页
└──────────────────────────────────────┘
```

## 为什么不能拿全局层写正文

从 `spine.md` 或 `outline.json` 直接写，只能写出**概括**：

- "他讲述了经过" —— 概括
- "他用三句话讲完，中间停了一次" —— 现场

前者就是 AI 味的来源。**散文的质感来自具体，具体只能来自页脚本。**

## 为什么不能只有局部层

只有逐页脚本，写到第 20 话时已经忘了第 3 话埋的伏笔，
于是人物崩、称谓乱、时间线冲突、每章都写成高潮。

`spine.md` 解决的是**跨话**问题，不解决**单场**问题。

## 硬规则

1. **S4 只做索引**：outline 里允许有 `pages: [12,13,14]`，不允许有可直接搬进正文的句子。
2. **S5 必须翻页脚本**：写到哪场，就打开那场的页脚本逐格过。只看 outline 写，视为违规。
3. **S3 不抽样**：页脚本是沉浸感的燃料，抽一页就少一页的现场。
4. **章节 1:1**：目标是还原完本，一话对一章，不合并、不拆分。
5. **spine 不做正文素材**：它的句子只出现在"查一致性"的时候。

## 判断一篇稿子有没有退化

| 症状 | 说明 |
|---|---|
| 通篇找不到具体动作或物件 | 在写概括 |
| 出现"讲述了/经过了/发生了" | 概括动词 |
| 整段没有一句台词 | 可能有，但要确认原作是否有对白 |
| 分镜的停顿全被填平 | 段落等长，没有空行与短句 |
| 同一段里三个人都"感到" | 补心理 |
| 动作/表情写得很密但页脚本里找不到 | 硬凑的微动作，是另一种 AI 味 |
| 场与场之间接不上，各场像并列 | `hook_in`/`hook_out` 没落到正文 |
