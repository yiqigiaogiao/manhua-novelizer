# 叙事风格配置（style.json）

> 正式改编前的**前置任务**。没有这份配置，不要批量写作。

## 为什么需要

同一套"小说化"写法套到不同作品上，会把《日月同错》写成通用网文，把轻松日常写成苦大仇深。
风格配置把"这部作品怎么讲故事"落成**可执行、可修改、可版本化**的条目，供每一话写作时读取。

## 文件位置与版本

```
<work>/
├─ style.json              当前生效版本
├─ style.md                渲染版（给 agent 直接读）
└─ style_history/
   ├─ style.v1.json        每次保存前的快照
   └─ style.v2.json
```

- `python scripts/style_config.py --action render` 生成 `style.md`
- `python scripts/style_config.py --action confirm` 标记"用户已确认"
- 修改后旧版本自动进 `style_history/`，可对比
- `confirmed=false` 时，写作步骤应拒绝批量开工

## 八个维度

| key | 维度 | 要回答的问题 |
|---|---|---|
| `rhythm` | 叙事节奏 | 快速推进／缓慢铺陈／密集反转／长时间停顿？各出现在哪类场景？ |
| `emotion` | 情绪表达 | 主要靠动作、表情、对白、心理、环境还是象征？ |
| `dialogue` | 对白特征 | 长短、信息密度、潜台词、停顿、幽默方式、角色间语言差异 |
| `visual` | 画面转译 | 动作分镜／特写／远景／重复构图／无对白画格各承担什么叙事作用 |
| `reveal` | 信息揭示 | 哪些直接告诉、哪些靠线索暗示、哪些延迟或反转 |
| `density` | 描写密度 | 不同场景中动作、对白、心理、环境、叙述的相对作用（**不设固定比例**） |
| `signature` | 特有习惯 | 反复出现的意象、幽默方式、互动模式、有辨识度的手法 |
| `forbidden` | 禁止破坏 | 克制的情绪、突然中断的对白、特定角色的沉默、刻意保留的信息差 |

## 结构

```json
{
  "version": 2,
  "confirmed": true,
  "source": "第1-10话 原图与对白",
  "updated_at": "2026-10-19T14:00:00",
  "dimensions": {
    "rhythm": {
      "label": "叙事节奏",
      "summary": "文戏以慢速铺陈为主，一场戏常停在静止画面上；战斗则突然提速，用短句与拟声推进。",
      "evidence": ["第9话 白小小跪坐尸场，连续三页几乎无对白", "第6话 三眼操控全村，一格一刀，节奏骤快"],
      "status": "已确认"
    },
    "emotion": {
      "label": "情绪表达方式",
      "summary": "极少直接写心理，靠手部动作、视线和沉默；悲痛场面反而用日常细节（数屋顶、扶门板）承载。",
      "evidence": ["第9话 白小小收尸时把镰刀朝里码齐"],
      "status": "已确认"
    }
  }
}
```

字段：

- `summary`：**可执行**的描述，不要"文笔优美""人物鲜明"这类空话。
- `evidence`：原作具体依据（话号 + 页码/画面），越具体越好。
- `status`：`已确认` / `待确认` / `尚未确认`。
- 资料不足时填 `尚未确认`，**不要凭空假设**。

## 使用规则（重要）

配置是**判断依据**，不是套版：

- 整体偏慢的作品，战斗场仍应快。
- 常用留白的作品，不是每场都要留白。
- 写每一场之前先问：这一场在原作里承担什么功能？再决定用哪几条配置。

## 修改流程

1. 用户直接编辑 `work/style.json`。
2. 保存（自动快照旧版）。
3. `python scripts/style_config.py --action render` 重新生成 `style.md`。
4. 后续生成一律读新版；旧版留在 `style_history/` 以便比较。
5. 重大修改后重跑一话样章，确认文风，再放量。
