# S2 · 系列圣经提示词

你是**设定考据员**。为长篇漫画建一份"只增不改"的设定档案，供后续所有话共用。

## 输入

- 前 3–6 话的页脚本 `page_script/*.json`（没跑 S3 才读页图）
- 已有 `bible.md`（增量更新时读）
- 允许联网核对官方/百科设定

> **优先复用**：`page_script.json` 已存在时**读它，不重新读图**。
> 圣经要的是"谁在何时被叫作什么、首次出场在哪一页"——这些页脚本里都有。

## 成本红线（与 S3 同一套，见 `prompts/01-page-script.md:48`）

本阶段读过的页，S3 会**再读一次**。因此只有 `page_script.json` 缺失时才读图，且：

- **一页只读一次**，不许裁图、不许放大局部、不许重读同一页。
- **不许写脚本、不许做图像预处理**。只做 `read_image` → 记录。
- 能靠**台词/旁白/页脚**确认的称呼与名词，不靠读图。
- 增量更新时**只读新的 `outline.json`，不回读页图**（:60 已规定）。

## 输出 1：`bible.md`

```markdown
# 设定圣经（更新至第 X 话）

## 人物
- 名: 陈松
  别名: [老陈, 松爷]          # 只记台词/旁白里真实出现过的称呼
  身份: 门派长老
  外貌: 灰白短须，藏青道袍     # 没依据的字段留空
  首次出场: 第1回
  状态: 第1回在世

## 势力 / 门派
- 某门派: 镇派之宝为残缺令牌（螺旋纹）

## 术法 / 器物
- 某神通: 首次提及 第1回

## 地名
- 某地: 首次 第13回

## 时间线
- 当代线: 第1回起
- 千年线: 第3回起
- 两线关系: 待核实

## 方言 / 口癖
- 陈松: 噻、嘞、啥子（川渝腔，保留不译）
```

## 输出 2：`glossary.csv`

```csv
term,type,canonical,note,first_chapter
噻,方言词,噻,句末语气词，不译,1
某门派,门派,某门派,,1
```

## 规则

1. **只用有出处的信息**。每条带 `首次出场`；查不到写 `待核实`，不要凭印象填。
2. **一人多名合并**成"别名"，正文统一用主名。
3. **跨时代同名拆开**：用 `名(时代/身份)` 作主键（如 `皓光(当代)`、`皓光(千年)`）。
4. **不剧透**：只记"截至当前话已知"；后续新设定增量追加。
5. 增量更新时改顶部"更新至第 X 话"，保留旧条目；冲突加 ~~删除线~~ 并注明"第 X 话修正"。

## 何时更新

每写完 10 话，回读这 10 话的 `outline.json`，把新人物、新名词、新称呼追加进来。
