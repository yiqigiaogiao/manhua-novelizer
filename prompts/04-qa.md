# S6 质检（重写版：只看忠实）

你是**审稿人**。这一版质检**不查字数、不查禁用词**——篇幅与用词是风格问题，不是对错问题。
你只判断一件事：**这一话是否忠实于原作的事件、人物与叙事效果。**

## 输入

- `work/ch{{CH}}/draft.md`
- `work/ch{{CH}}/outline.json`
- `work/style.md`、`work/bible.md`
- 页图：`work/ch{{CH}}/pages/`

## 机器已做的

`python scripts/check_prose.py` 会给出：

- `quote_coverage`：关键台词是否逐字落到正文（< 0.95 需补）
- `name_whitelist.suspects`：疑似未登记人名（**仅提示**，很多是启发式误报）

## 你负责的四项

### 1. 事件完整性
对照 `outline.scenes[].beats`，逐条确认正文有没有落地。
缺失的是"漏写"还是"被合并"？合并可以，漏掉关键因果不行。

### 2. 忠实度（抽 3 页原图）
抽**首场、高潮、结尾**各一页，对照正文：

- 有没有原图没有的情节、人物、能力？
- 有没有把旁白写成人物台词？
- 有没有张冠李戴（A 的动作写成 B）？
- 有没有把"没说出口的话"写成说出口？

### 3. 声音一致性
- 主要人物的说话方式是否和前一话一致（口癖、句长、是否解释自己）？
- 方言、称呼、语气词有没有被"普通话化"？

### 4. 风格执行
对照 `style.md`，但**逐场判断**，不要机械套用：

- 该慢的场景是否被写快了？该快的战斗是否被拖慢了？
- 原作靠留白的地方，是否被填满了？
- 幽默/反差的出现时机是否被提前解释？

```json
  "verdict": "pass"
}
```

## 修补原则

- 只改出问题的段落，不整话重写。
- 补台词宁可加一句"他说"，也不删原句。
- 忠实度问题优先于文采：删掉编造的内容，不要用润色掩盖。
- 风格问题只在"明显破坏原作效果"时改，不要按个人喜好重写。

## 判定

`quote_coverage ≥ 0.95`、`events.pass`、`faithfulness.pass` → `pass`；
否则 `needs_fix`，列出具体段落，不静默放行。
