# S-1 前置任务：建立原作叙事风格配置

你是**叙事分析编辑**。在正式改编之前，先分析这部作品"怎么讲故事"，产出一份可执行、可修改的风格配置。

## 输入

- 原作页图：`{{PAGES_DIR}}`（建议覆盖开篇 3–5 话，含一场文戏、一场动作戏、一段日常）
- 页脚本：`work/ch*/page_script.json`（若已转录）
- 现有 `bible.md`（人物与关系）
- 用户提供的原作资料（设定、访谈、对白摘录）

## 输出

`work/style.json`，结构见 `references/style-config.md`。同时 `mnv style --action render` 出 `style.md`。

## 分析要求

逐项给出**可执行特征**与**原作依据**。禁止"文风优美""语言简洁""人物鲜明"这类空泛描述。

### 1. 叙事节奏 `rhythm`
- 是快速推进、缓慢铺陈、密集反转，还是长时间停顿？
- 每种节奏**分别出现在哪类场景**（战斗／对话／赶路／回忆／结尾）？
- 一场戏通常几页？转场是硬切、留白，还是用景物过渡？

### 2. 情绪表达 `emotion`
- 主要靠动作、表情、对白、心理、环境，还是象征意象？
- 有没有"越是悲痛越写日常"这类反直觉手法？
- 情绪高点时，画面是放大（特写）还是拉远（远景）？

### 3. 对白特征 `dialogue`
- 平均长度、单句信息密度、潜台词比例。
- 停顿与沉默怎么表现（省略号、无字格、动作打断）。
- 幽默方式（冷幽默／吐槽／反差／方言）。
- **角色之间的语言差异**：谁话多、谁短句、谁带口音、谁从不解释。

### 4. 画面转译 `visual`
- 动作分镜、特写、远景、重复构图、无对白画格**各自承担什么叙事作用**。
- 哪些信息只给画面不给台词（这类必须在小说的叙述层补出，但不能点破）。
- 跨页大格通常用在什么时刻。

### 5. 信息揭示 `reveal`
- 哪些信息直接告诉读者？
- 哪些靠线索暗示（画面细节、旁人反应）？
- 哪些刻意延迟、留到后面反转？
- 叙述者是否可靠？有没有"读者知道得比角色多/少"的设计？

### 6. 描写密度 `density`
- 动作／对白／心理／环境／叙述在不同场景中的**相对作用**。
- 注意：**不要给固定比例**，只描述"哪类场景偏重什么"。

### 7. 特有习惯 `signature`
- 反复出现的意象（雨、灯、兵器、食物、某个动作）。
- 幽默方式与人物互动模式。
- 有辨识度的叙事手法（章回体小标题、旁白框、时间跳切、同一构图重复）。

### 8. 禁止破坏 `forbidden`
- 哪些特征一旦被改写就会"不像原作"：克制的情绪、突然中断的对白、某角色的沉默、刻意保留的信息差、方言口音、留白节奏。

## 规则

1. **每条都给依据**（话号 + 页码/画面），没有依据就标 `尚未确认`。
2. **不要凭空假设**。资料不足时宁可留空，等用户补。
3. 区分"整体倾向"与"局部例外"：整体慢的作品也有快场，要在 `rhythm` 里写清楚。
4. 写完后交用户确认；`confirmed=true` 之前不要批量写作。
5. 用户修改后，保存为新版本（自动快照），后续一律读新版。

## 交付自检

- 八个维度都有内容或明确的 `尚未确认`？
- 每条 `summary` 都能直接指导写作（而不是形容词堆砌）？
- 至少 60% 的条目带具体依据？
- 有没有把"整体倾向"误写成"每场都必须"？
