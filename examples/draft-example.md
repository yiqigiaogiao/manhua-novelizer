# 第一回 试作

正殿的香烧到一半，灰落在青砖上，没人去扫。陈松把令牌按在案面上，指腹在缺角上蹭了一下，蹭掉一点浮灰。

"只有咱们这一门噻！"他抬眼看过去。

阿禾没有接话，视线落在那道缺口上，喉结轻轻动了一下。缺成这样，也能叫镇派之宝？他张了张嘴，到底没出声。

"你晓得个啥子。"陈松把声音压低，窗纸的白光落在他半张脸上，另一半沉在阴影里。

◇

山道上的雪化了一半，泥水浸到靴面。阿禾走在前面，忽然停下："师父，那令牌为什么缺一角？"

陈松没有答。他把手拢进袖子，望着远处那道白线。风从坡上下来，卷起他衣角。
